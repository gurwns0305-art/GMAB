# GARCH 원본 유지 · 데이터 교체 패키지

VS Code: ZIP 압축을 풀고 **이 폴더 전체**를 엽니다. GARCH_reordered.ipynb를 실행합니다.
필요하면 터미널에서 python -m pip install -r requirements.txt로 라이브러리를 설치하고 Python 커널을 선택합니다.
Colab: 노트북을 연 뒤 모두 실행, NAV_date_aligned.csv와 male_60_69_mortality.csv 두 파일을 업로드합니다.
사망률 파일을 처음에 올리지 않았다면 왼쪽 파일 창에서 추가 업로드 후 사망위험 셀부터 실행합니다.

## 이번 변경 범위
- 기준 파일은 사용자가 지정한 GARCH_reordered.ipynb. 원본도 별도 동봉했습니다.
- 코드 셀 1: 동봉 데이터 자동 읽기 및 VS Code/Colab 로딩 호환.
- 코드 셀 3: 학습 2012~2014 / 테스트 2015~2025로 기간만 교체.
- 코드 셀 22: 미정의 gmab_price를 원래 가격계산 결과인 put_price에 연결하는 한 줄.
- 나머지 코드 셀은 원본과 문자열까지 동일함을 검사했습니다. 셀 순서/수도 유지했습니다.
- 오래된 출력은 제거했습니다. 이전에 새로 만든 GMAB 연구 노트북은 이 패키지에 합치지 않았습니다.

## 데이터
원본 NAV CSV의 기준가를 기존 입력 스키마 NAV_KRW로 변환했습니다.
원본 노트북의 가정대로 valuation_date_T_minus_1 = disclosure_date − 1달력일이며 평일 필터·252일 설정도 유지합니다.
이 가정은 실제 거래일이나 공시시각의 독립 검증 결과가 아닙니다.
변환일 기준 2011~2025 전체 자료를 담아 2012년 첫 수익률의 직전 관측값을 유지했습니다.
따라서 2025-12-31 변환일 가격에는 2026-01-01 공시 행이 필요하며 실제 원본 값을 사용했습니다.
데이터 학습/테스트 구분은 원본처럼 변환된 date 기준입니다.
2015~2025 전체는 11개 연도입니다. 기존 Monte Carlo 보증기간 T=10을 임의로 11년으로 바꾸지 않았습니다.
동봉 사망률 파일은 사용자의 Downloads에 있는 기존 파일을 복사한 것이며 출처를 새로 검증하거나 값을 수정하지 않았습니다.

data_and_change_audit.json과 cell_*_changes.diff에서 변경 내역을 확인할 수 있습니다.
